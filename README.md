# 日本株ひとこと投資メモ

日本株ひとこと投資メモは東証市場再編・証券コード英文字組入れ対応版です。

「日本株投資ひとことメモ」は、日本の株式市場での投資を気軽に管理することができるツールです。\
ひとことで投資の意図やアイデアを記録できるので日本株投資をするにあたり手軽に利用できるのが魅力です。\
また日本株投資ひとことメモを使えば日々の投資をよりスムーズに管理できるようになります。

## 📱 アプリの特徴

- **銘柄管理**: 日本株の証券コードと銘柄名を簡単に登録
- **ひとことメモ**: 投資の理由や戦略を短文で記録
- **東証市場再編対応**: プライム・スタンダード・グロース市場に対応
- **証券コード英文字組入れ対応**: 新しい証券コード体系に完全対応
- **いきなり入力機能**: アプリ起動と同時に入力画面を表示
- **オフライン動作**: インターネット接続不要でローカル保存

## 📱 基本的な使い方

1. **新規メモの作成**

   - 「+」ボタンをタップして新規作成画面に移動
   - 証券コードを入力（4 桁の数字または英文字を含むコード）
   - 銘柄名とひとことメモを入力して保存

2. **いきなり入力機能**
   - 設定画面で「いきなり入力」を有効にすると、アプリ起動時に直接入力画面が表示されます
