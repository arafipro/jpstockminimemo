# タスク 1.4.3 簡単テスト方法

## 🎯 テストの目的

**オフライン時でも課金状態が表示されることを確認**

---

## 🚀 簡単 3 ステップテスト

### **ステップ 1: テスト状態を保存**

1. アプリを起動
2. 設定画面を開く（右上の設定アイコン）
3. 「テスト状態を保存」ボタンをタップ
4. ✅ 成功メッセージが表示されれば OK

### **ステップ 2: オフラインで確認**

1. デバイスの Wi-Fi/モバイルデータをオフにする
2. 「保存された状態を取得」ボタンをタップ
3. ✅ 状態が表示されれば OK

### **ステップ 3: メイン画面で確認**

1. メイン画面に戻る
2. ✅ サブスクリプション状態が表示されれば OK

---

## 📱 実際の操作手順

### **1. アプリ起動**

```bash
flutter run
```

### **2. 設定画面でテスト**

- メイン画面の右上の設定アイコンをタップ
- 設定画面の下部にある「オフラインサブスクリプション管理テスト」セクションを確認

### **3. テスト実行**

1. **「テスト状態を保存」** → 成功メッセージを確認
2. **「保存された状態を取得」** → 状態詳細を確認
3. **「ネットワーク状態を確認」** → オンライン/オフラインを確認

### **4. オフラインテスト**

1. デバイスの Wi-Fi/モバイルデータをオフ
2. 「ネットワーク状態を確認」→ 「オフライン」と表示されることを確認
3. 「保存された状態を取得」→ オフラインでも状態が取得されることを確認

### **5. メイン画面確認**

- メイン画面に戻る
- サブスクリプション状態が表示されることを確認

---

## ✅ 成功の確認ポイント

| 項目           | 確認方法                       | 期待される結果                     |
| -------------- | ------------------------------ | ---------------------------------- |
| 状態保存       | 「テスト状態を保存」ボタン     | 成功メッセージが表示               |
| 状態取得       | 「保存された状態を取得」ボタン | 状態詳細がダイアログで表示         |
| オフライン対応 | Wi-Fi をオフにして状態取得     | オフラインでも状態が取得される     |
| メイン画面表示 | メイン画面に戻る               | サブスクリプション状態が表示される |

---

## 🚨 問題が起きた場合

### **よくある問題**

- **保存に失敗**: アプリを再起動して再試行
- **状態が取得できない**: 先に「テスト状態を保存」を実行
- **ネットワーク状態が分からない**: デバイスの設定で Wi-Fi/モバイルデータを確認

### **デバッグ情報の確認**

- 「デバッグ情報を表示」ボタンで詳細情報を確認
- `isInitialized: true` になっているか確認
- `hasSavedData: true` になっているか確認
